# Revisión de VillalbillaCF — 22 de octubre de 2026

Copia corregida: versión 0.1.7, Android versionCode 10. Copia preparada para una rama de prueba privada y una APK interna; no se ha publicado en tiendas.

## Correcciones

- Solicitudes de equipo: solo se actualizan los campos permitidos por Firestore, sin enviar el identificador local `id`.
- Registro: no se intenta cargar un perfil privado con un correo sin verificar. Si falla la verificación enviada, se cierra la sesión no verificada.
- Permisos: la gestión observa el perfil y abandona el área privada si se retira la aprobación. Las cargas antiguas no restauran una cuenta después de cerrar la sesión.
- Enlace de acceso por correo: se evita procesarlo dos veces y se limpia la dirección web después de usarlo.
- Guardado: las escrituras de un dispositivo se realizan en orden y un fallo no bloquea las siguientes. Esto no resuelve la edición simultánea entre varios dispositivos.
- Carga inicial: se permite reintentar sin sobrescribir datos que no se hayan cargado.
- Vídeo: se codifican apóstrofos y otros caracteres de nombres/títulos. La preparación del césped en web utiliza Expo Asset, en lugar de `Image.resolveAssetSource`, que no existe en React Native Web.
- Google nativo: la configuración se prepara al pulsar el acceso, con validación explícita del cliente iOS. Se evita iniciar una configuración incompleta al cargar el módulo. El esquema de retorno iOS se obtiene del cliente iOS configurado, en lugar de reutilizar un valor fijo.
- Expo se actualiza de 55.0.31 a 55.0.32. Se actualizan los dos archivos de dependencias bloqueadas. La nueva versión 0.1.7 separa esta compilación nativa de la anterior para EAS Update.
- `.env.example` contiene la configuración pública de Firebase verificada en el proyecto del club y la URL del servidor existente. No contiene contraseñas, tokens de administrador ni claves privadas. Copiarlo a `.env` antes de compilar. Los identificadores OAuth públicos de Google se han completado con los valores verificados en Expo.

## Pruebas automáticas

`npm test` supera las pruebas originales de fechas/enlaces y dieciocho pruebas adicionales de acceso, perfiles, guardado, vídeo, respuestas HTTP y configuración Google Android/iOS. Firebase y las funciones del navegador se simulan en las pruebas unitarias; no sustituyen una prueba en un teléfono.

La exportación de paquetes web, Android e iOS con `npx expo export --platform all` se comprueba después de los cambios. Produce paquetes JavaScript/Hermes; no es una compilación firmada APK/IPA ni una instalación en un dispositivo.

## Ejecutar esta copia

Usar Node 24:

```sh
cp .env.example .env
npm ci
npm test
npx expo export --platform all
npm run serve
```

Abrir `http://127.0.0.1:8081` en ese ordenador. En móviles se usa el servidor HTTPS configurado. El acceso nativo con Google requiere generar y probar una compilación nativa; no se debe prometer funcionamiento en Expo Go con módulos nativos personalizados.

## Bloqueo al abrir Entrenadores en la APK Android

La captura del usuario muestra el error genérico de carga antes de entrar al equipo. Todavía no identifica la excepción original: puede venir del almacenamiento local, de Firebase o de la mezcla de los registros. No se ha inspeccionado la memoria de su teléfono ni se ha reproducido en esa APK.

Se reproduce y corrige una causa del mismo bloqueo: las copias antiguas que carecen de nuevos campos se rechazaban antes de cargar la nube. Ahora se completan los campos ausentes, se conserva la copia anterior exacta antes de habilitar escrituras y se mantienen los registros locales y de nube. Una copia dañada solo se sustituye con una copia de nube válida y después de respaldar los bytes anteriores. Si fallan permisos, conexión, formato o respaldo, no se habilita el guardado ni se sobrescriben los datos.

La pantalla de fallo muestra un mensaje específico y una referencia de diagnóstico, con Reintentar, Cerrar sesión y Volver a Noticias. Firebase sin configurar ya no se trata como una lectura vacía o un guardado correcto.

Siete pruebas nuevas cubren migración de datos antiguos, combinación sin pérdida, rechazo de permisos, recuperación con respaldo, respaldo fallido, formatos de nube incompatibles y mensajes de conexión/sesión. La exportación Android se ha repetido tras esta corrección.

Para comprobar la solución en el teléfono falta generar e instalar una APK compatible con su firma y configuración. No se ha enviado una actualización OTA.
