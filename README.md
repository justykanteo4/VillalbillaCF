# VillalbillaCF Android 0.1.11

Configuración nativa de Firebase y notificaciones incluida. Código Android 17.

- VillalbillaCF-0.1.11.apk: para actualizar el APK 0.1.9 distribuido en las ramas de este repositorio, con su mismo certificado de pruebas.
- VillalbillaCF-0.1.11-Expo.apk: para actualizar el APK 0.1.8 de Expo/EAS, con su firma remota.

Instalar encima de la versión compatible, sin desinstalar. Ambos archivos contienen la misma app y soportan Android ARM64/ARMv7, desde Android 7. La recepción de avisos requiere comprobarla en un dispositivo físico.

Código y comprobaciones: rama fix/android-push-config, commit 6843fbb. No se han enviado avisos reales.
